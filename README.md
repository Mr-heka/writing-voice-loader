# Writing Voice Loader

Builds a voice sheet from things you have really written, then edits AI drafts to match it, section by section, and shows what changed.

**Who it is for:** Anyone whose emails and proposals go out under their name and sound a bit like a chatbot.

**What you need:** Claude Code or Codex and three to five things you wrote yourself. It can use the free Humanizer skill alongside if you have it.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
